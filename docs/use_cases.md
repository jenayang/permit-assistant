# 주요 사용 시나리오

## 시나리오 1: 신축 건물 카페 창업

**사용자 상황**: 강남구 신축 건물 1층에 20평 카페 오픈

**예상 대화**: 
사용자: 강남구에 20평 카페 열려고 해. 신축 건물 1층인데 뭐 준비해야 해?
챗봇:
[상황 분석]

신축 건물의 근린생활시설(카페)
연면적 20평(약 66㎡)
100㎡ 미만 → 건축신고 대상

[필요 절차]

건축신고 (관할 구청 건축과)
위생 신고 (관할 구청 위생과)
사업자등록 (세무서)

[필수 서류]

건축신고서
위생업 신고서
배치도, 평면도
임대차계약서
...

[사전 진단]
⚠️ 주차: 근생시설 부설주차장 기준 확인 필요
⚠️ 소방: 200㎡ 미만이라 소방시설 완비증명 대신 신고
⚠️ 정화조: 좌석 수 기준 용량 확인
⚠️ 배기: 조리기구 있으면 배기시설 필요
⚠️ 접도: 4m 이상 도로 접해야 함
[예상 소요 기간]
서류 준비 1-2주 + 심의 2주 = 총 3-4주

## 시나리오 2: 용도변경 (사무실 → 카페)

**사용자 상황**: 기존 사무실 자리를 카페로 변경

**챗봇 응답 방향**:
- 동일 시설군(제2종 근린생활시설) 내 변경인지 확인
- 건축물대장 기재변경으로 가능한지 판단
- 소방 사전 협의 안내
- 인테리어 시 구조 변경 여부 확인

## 시나리오 3: 대수선 관련

**사용자 상황**: 리모델링 시 구조 변경 필요

**챗봇 응답 방향**:
- 대수선 대상인지 판별
- 대수선 신고 vs 허가 구분
- 구조 안전 검토 필요성
- 안전진단 결과 반영

## 시나리오 4: 사전 진단만 요청

**사용자 상황**: 특정 문제 확인만

**챗봇 응답 방향**:
- 사용자가 지정한 항목 집중 진단
- 관련 규정 정확한 인용
- 대응 방법 안내

## 시나리오 5: 절차 문의만

**사용자 상황**: 뭐부터 해야 할지 로드맵 필요

**챗봇 응답 방향**:
- 단계별 로드맵 제공
- 각 단계별 소요 시간
- 병렬 진행 가능한 부분 안내
