### 별표가 이미지로 박혀 텍스트 추출이 안 되는 경우

일부 조례 PDF는 별표(첨부 표)가 스캔 이미지라 텍스트로 안 뽑힌다(주차장
조례에서 실제로 발생). 이럴 땐 국가법령정보센터에서 해당 별표만 **한글
(hwp)** 파일로 따로 받아 같은 폴더에 넣으면 된다 — 자동으로 인식돼서
`[별표N]`으로 인덱싱됨. 별지서식(신청서 양식)은 규정 내용이 아니라서 hwp로
받아도 인덱싱에서 제외됨.

## 절차 안내 문서

### 필수 자료

**서울시 건축행정 안내**:
- 건축신고 처리 절차 안내
- 용도변경 신고/허가 안내
- 사용승인 신청 안내

**국토교통부 자료**:
- 건축물의 용도변경 절차 안내

이런 자료는 각 지자체 홈페이지 "건축과" 또는 "민원안내" 섹션에서 다운로드 가능.

## 데이터 정리 규칙

### 폴더 구조

- `data/laws/`: 법령 원본
- `data/ordinances/`: 조례 원본
- `data/procedures/`: 절차 안내 문서
- `data/samples/`: 테스트용 (커밋 가능)
