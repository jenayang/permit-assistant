# Phase 1: MVP 로드맵

**목표**: 서울시 소규모 카페 창업 인허가 사전진단 챗봇 완성

**예상 기간**: 2주

## 완료 조건

- [ ] 카페 창업 관련 질문 10개에 정확한 답변 (평가셋 5개 확보, Gemini 무료 티어 할당량으로 전체 실행 보류 중)
- [ ] 3가지 인허가 케이스 커버 (신축, 용도변경, 대수선) — 시스템 프롬프트 반영 완료, 실제 질의 검증 대기 중
- [x] 사전 진단 5가지 항목 이상 자동 감지 (주차·정화조·소방·장애인 편의시설·위생)
- [ ] 근거 법령/조례 정확한 인용 — 인용 형식 요구는 프롬프트에 명시, 정의성 질문(예: 건폐율) 검색 버그 수정 완료, 전체 검증은 대기 중
