# 법령 해석 결정 사례 모음

판정 규칙 변경은 사용자 결정 사항([[rule-engine-vs-llm]])이다. 실제로
법령 원문을 RAG로 직접 대조해서 규칙을 고친 사례들을 모아둔다 — 비슷한
해석 질문이 다시 나오면 여기부터 확인.

## 건축사 설계 의무 (건축법 제23조ᆞ제19조6항)

`requires_licensed_architect()`(`permit.py`). 신축ᆞ이전은 규모 무관 항상
필요. 85㎡ 미만 증축ᆞ개축ᆞ재축, 200㎡ 미만ᆞ3층 미만 대수선은 예외(건축사
없이 개인 가능). 용도변경은 허가 대상(상위군 이동)이면서 500㎡ 이상일
때만 준용.

미확정 부분: 제23조1항3호("대통령령으로 정하는 건축물")ᆞ제23조4항
(표준설계도서)은 시행령ᆞ고시가 있어야 확정되는데 미인덱싱 — 반영 안 됨
(과대판정 방향으로 안전하게 둠).

## 식품 "완제품만 판매" (식품위생법 시행령 제21조ᆞ시행규칙 제39조)

`classify_food_business()`(`food_safety.py`). 과거 "조리 없이 완제품만
판매"를 즉석판매제조ᆞ가공업으로 오판정했었다 — 그 업종은 "제조ᆞ가공"이
요건이라 완제품 되팔기와 안 맞음. 올바른 갈림: 완제품만 판매 + 영업장
300㎡ 이상 → 기타식품판매업(신고 대상), 300㎡ 미만 → 신고대상제외(어느
종류에도 미해당, 확정 판정이지 "판정 불가"가 아님).

미지원(의도적): 반찬가게ᆞ떡집처럼 직접 제조ᆞ가공해 포장 판매하는 진짜
즉석판매제조ᆞ가공업은 음식점과의 법적 구분이 미묘하고 타깃 스코프 밖 —
자동 판정 안 함.

상세: `docs/project_report.md` 4-15, 그리고 이 결정에 이르는 세션 대화
(건축법 제23조는 별도 세션에서 원문 대조로 발견됨).
