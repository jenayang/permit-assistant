# 외부 정부 API 재시도 — 5xx만, 1회만

**원칙**: 외부 API(건축HUB 등) 호출이 실패하면 5xx(서버 쪽 순간 오류)일
때만 짧게(1초 간격) 1회 재시도한다. 4xx(서비스키ᆞ파라미터 오류처럼
재시도해도 똑같이 실패)는 재시도 대상에서 제외해 불필요한 지연을 막는다.

**왜**: 같은 요청을 몇 초 뒤 그대로 재실행하면 정상 200이 오는 걸 실측
확인 — 정부 API 쪽의 일시적 불안정성. 무조건 폴백(사용자에게 직접 입력
요청)으로 넘기기 전에 이 패턴부터 시도할 것.

**새 외부 API 연동 시 재사용**: 상태 코드로 분기(5xx만 재시도) + 짧은
대기 + 횟수 제한(무한 재시도 금지).
