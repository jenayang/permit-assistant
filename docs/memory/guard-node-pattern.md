# guard_node — 프롬프트로 안 되면 그래프 레벨 사후 검증

**원칙**: 프롬프트로 아무리 강하게 지시해도 LLM이 무시하는 사례가 반복
확인되면, `guard_node`가 매 턴 자유 텍스트 답변을 정규식+상태로 **사후
검증**하고 위반 시 같은 턴 내 1회 재시도를 유도한다.

**지금 있는 체크(6개)**: ① 단계 몰아주기 ② 근거 없는 인용 ③ synthesis 기록
누락 ④ 건축물대장 조회 후 시설군 미기록(현재는 코드가 자동 파생 — 발동
빈도 자체가 줄음) ⑤ 식품/소방/간판 판정 누락 ⑥ Step2 안내를 RAG 없이 설명.

**커버리지는 의도적으로 불균등**: 실측으로 확인된 사고 하나당 체크 하나만
추가한다. 일반 프레임워크를 미리 만들지 않는다 — 추측성 체크는 안 만듦.
그래서 아직 안 걸린 유사 사고가 남아있을 수 있음(알려진 한계, 의도적).

**guard보다 먼저 고려할 것**: "잡아서 재시도"보다 "애초에 못 하게" 만드는
`tool_choice` 강제가 가능하면 그쪽이 우선. guard=사후 교정,
tool_choice=사전 예방, 둘 다 필요하지만 성격이 다르다.
