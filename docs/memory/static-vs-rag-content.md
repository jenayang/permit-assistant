# 정적 콘텐츠 vs RAG — 언제 전환하나

**원칙**: 관련 법령이 인덱스에 없으면 원문 대조 후 정적 텍스트로 먼저
채운다. 이후 그 법령을 실제로 확보ᆞ인덱싱한 뒤 **"정적 vs RAG 비교
검증"을 통과해야만** RAG로 전환한다 — 검증 없이 먼저 바꾸지 않는다.

**검증된 사례**: 사업자등록ᆞ위생교육ᆞ공사ᆞ4대보험 4개 도메인 전부 RAG가
정적 콘텐츠와 동일하거나 더 상세한 결론에 도달함을 확인 후 전환. 법 개정
시 재인덱싱만 하면 자동 반영됨.

**전환하지 않는 것**: 법령 근거가 아예 없는 순수 실무 체크리스트(인테리어ᆞ
장비 설치, 영업 시작 항목)는 검색할 조항 자체가 없어 의도적으로 정적
유지 — "전환 가능한 것만 전환"이 원칙.
